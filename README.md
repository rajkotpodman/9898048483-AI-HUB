- 🎛️ **Granular Catalog Controls**: Filter models instantly by category, login requirement, pricing tier, and privacy level.

## 🛠️ Build & Installation Instructions

### Prerequisites
- Node.js 22+ / Bun 1.x
- Android SDK 37 (for mobile APK builds)
- JDK 17

### Web Development Server
```bash
# Install dependencies
npm install

# Run development server on port 3000
npm run dev
```

### Production Build
```bash
# Build production bundle
npm run build

# Start production server
npm start
```
